# Predictive Coding

## Definition

Predictive coding is a family of computational models proposing that
neural systems can represent information through predictions and
prediction errors within hierarchical processing systems.

A simplified architecture consists of:

**Higher-level prediction**
↓
**Lower-level representation**
↓
**Prediction error**
↑
**Model updating**

Predictive coding is one important component of the broader family of
predictive-processing theories.

---

## Historical Importance

Rao and Ballard (1999) proposed a computational model of predictive
coding in the visual cortex.

Their model suggested that higher cortical levels could generate
predictions about lower-level activity, while lower levels could
represent residual errors between predicted and actual activity.

The model reproduced several properties of visual receptive fields.

This was an influential computational result, but it did not establish
that the brain literally implements the proposed architecture in every
respect.

---

## Hierarchical Architecture

Predictive-coding models commonly assume hierarchical processing.

Higher levels:

- represent more abstract causes;
- generate predictions;
- provide contextual information.

Lower levels:

- process more detailed information;
- represent mismatches;
- transmit information relevant to model updating.

The exact neural implementation remains an active research question.

---

## Top-Down Predictions

Predictions are generally represented as top-down influences.

Conceptually:

**Higher level**
↓
prediction
↓
**Lower level**

The lower level can compare this prediction with incoming sensory
information.

---

## Prediction Errors

Prediction errors represent discrepancies between expected and
observed information.

Conceptually:

**Prediction error = observation − prediction**

Different predictive-coding models make different assumptions about:

- what constitutes the error;
- where it is represented;
- how it is weighted;
- how it is transmitted;
- how it changes higher-level representations.

Therefore, prediction error should not be treated as a single,
universally defined neural quantity.

---

## Predictive Coding vs Predictive Processing

Predictive coding is generally narrower than predictive processing.

A useful distinction is:

**Predictive coding**
→ specific computational models of hierarchical prediction and error.

**Predictive processing**
→ broader family of theories concerning prediction, inference,
perception, cognition, and action.

The terms are sometimes used interchangeably in the literature, but
they should be distinguished when precision matters.

---

## Evidence Status

Evidence exists for prediction-related processing in the nervous system.

However, whether the brain implements a single canonical predictive
coding architecture remains unresolved.

Some neural findings interpreted as prediction errors can potentially be
explained by alternative feedforward or recurrent mechanisms.

Therefore:

**Predictive coding is an influential computational framework, not a
settled complete description of neural computation.**

---

## Relationship to Psychosis

Predictive-coding models have been used to investigate:

- hallucinations;
- delusions;
- perceptual inference;
- altered salience;
- agency;
- source monitoring.

These applications remain active research areas.

No single predictive-coding mechanism has been established as the
cause of schizophrenia.

---

## Relationship to PIF

Predictive coding provides a possible computational foundation for
studying precision.

PIF proposes that instability in precision maintenance or allocation
might contribute to disturbances across multiple psychological domains.

This remains a hypothesis requiring empirical testing.
