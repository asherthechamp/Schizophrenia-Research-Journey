## LinkedIn Post

Cognitive control is often described as the ability to stop yourself from doing something.

But inhibition is only one part of a much larger system.

Cognitive control helps us:

- maintain goals
- select relevant information
- manage competing signals
- suppress inappropriate responses
- monitor performance
- detect conflict and errors
- adapt when circumstances change
- switch strategies when necessary

A useful conceptual map is:

Goal → Maintenance → Selection → Competition Management → Inhibition → Action → Monitoring → Adaptation

This changes how we think about schizophrenia.

Rather than asking whether schizophrenia is simply a "cognitive-control disorder," a more useful scientific question is:

**Which control processes are altered, under what conditions, and through which mechanisms?**

This is also where cognitive neuroscience begins to connect naturally with computational psychiatry.

The larger question is becoming:

**How does the brain control cognition when the signals it must regulate are generated from within?**

## Facebook Post

What happens when the brain has a goal but many competing signals are active at the same time?

This is where cognitive control becomes important.

Cognitive control helps organize thought and behavior around goals. It involves maintaining relevant information, selecting what matters, managing competition, suppressing inappropriate responses, monitoring what happens, and adapting when circumstances change.

This is why cognitive control is broader than inhibition.

In schizophrenia research, this distinction matters. Findings from individual tasks should not automatically be interpreted as evidence for one universal "control deficit."

Instead, we can ask more precise questions:

Which processes are affected?

Under what conditions?

How do these processes interact?

And what mechanisms might explain the observed behavior?

These questions connect cognitive neuroscience with computational psychiatry—and eventually with the deeper question of how internally generated mental activity is regulated.
